# Realty Photo AI

Веб-приложение для агентов недвижимости: улучшает фото объектов через [fal.ai](https://fal.ai).
Интерфейс на трёх языках: **русский, español, English** (переключатель в шапке, язык запоминается).

## Что умеет
- ✨ **Авто‑улучшение** — свет, HDR (окна не пересвечены), баланс белого, ровные вертикали
- 🛋️ **Виртуальный стейджинг** — мебель в пустой комнате, 7 стилей, выбор типа комнаты
- 🧹 **Убрать хлам** · ⬜ **Пустая комната** · 🎨 **Освежить ремонт**
- ☀️ **Замена неба** · 🌆 **Вечерняя (twilight) съёмка** · 🌿 **Благоустройство двора**
- 🔍 **Апскейл ×2** (SeedVR2) — отдельно или после любой обработки
- ✍️ **Своя задача** — инструкция текстом на любом языке
- Пакетная обработка (до 3 фото параллельно), слайдер «до/после», полноэкранное сравнение
- Пометка «Виртуальный стейджинг» на скачанных фото на языке интерфейса (можно выключить)

Модели: `fal-ai/nano-banana-pro/edit` (качество), `fal-ai/nano-banana/edit` (быстрее/дешевле), `fal-ai/seedvr/upscale/image`.

## Переменные окружения
| Переменная | Обязательна | Описание |
|---|---|---|
| `FAL_KEY` | да (на сервере) | Ключ fal.ai — https://fal.ai/dashboard/keys. Хранится на сервере, в браузер не попадает |
| `APP_PASSWORD` | рекомендуется | Пароль на вход в приложение (логин любой). Без него любой, у кого есть ссылка, тратит ваш баланс fal |
| `PORT` | нет | Порт (Railway задаёт сам) |

Если `FAL_KEY` не задан, ключ можно вставить прямо в интерфейсе — он хранится только в браузере пользователя.

## Запуск локально
Нужен Node.js 18+. Зависимостей нет.

```bash
FAL_KEY=ваш_ключ npm start
# http://localhost:3000
```

## Деплой на Railway
1. New Project → Deploy from GitHub repo → этот репозиторий.
2. Variables: `FAL_KEY`, `APP_PASSWORD`.
3. Settings → Networking → Generate Domain.

Railway сам определит Node-проект и запустит `npm start`. Проверка здоровья: `GET /health`.

## Важно
Виртуальный стейджинг и замена неба меняют фото. На многих порталах (Idealista, Fotocasa, MLS) такие фото нужно помечать — поэтому пометка включена по умолчанию. Не скрывайте реальные дефекты объекта.
