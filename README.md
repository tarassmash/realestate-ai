# Realty Photo AI

SaaS для агентов недвижимости: улучшение фото объектов через [fal.ai](https://fal.ai) с оплатой за пакеты фото.
Интерфейс: **русский, español, English**.

## Что внутри
- **Лендинг** (`/`) — продающая страница: демо «до/после», возможности, тарифы, FAQ, реферальная программа
- **Приложение** (`/app`) — обработка фото, баланс, история, приглашение коллег
- **Админка** (`/admin`) — выручка, конверсия, пользователи, ручное начисление кредитов, блокировка, сброс пароля

### Инструменты
Авто‑улучшение (HDR, свет, вертикали) · Виртуальная меблировка (7 стилей) · Убрать хлам · Пустая комната · Замена неба · Вечерняя съёмка · Благоустройство · Освежить ремонт · Апскейл ×2 · Своя задача текстом.

### Монетизация
| | |
|---|---|
| Бесплатно при регистрации | 5 фото (`FREE_CREDITS`) |
| Старт | 20 фото — €12 |
| Профи | 60 фото — €29 |
| Агентство | 200 фото — €79 |
| Стоимость | 1 фото = 1 кредит, 4K = 2 кредита, апскейл бесплатно |
| Рефералка | приглашённый +3 фото, пригласивший +10 после первой покупки друга |

Себестоимость на fal: ~$0.15 за фото (2K), ~$0.30 (4K) → маржа 65–75%.
Кредиты не сгорают. При ошибке обработки кредит возвращается автоматически.
Оплата — Stripe Checkout (карты, Apple Pay, Google Pay), счёт (invoice) отправляется клиенту на email.

## Подключение Stripe
1. Зарегистрируйтесь на https://dashboard.stripe.com и пройдите верификацию (нужна для живых платежей).
2. **Developers → API keys** → скопируйте *Secret key* → `STRIPE_SECRET_KEY`.
3. **Developers → Webhooks → Add endpoint**:
   - URL: `https://ВАШ-ДОМЕН/api/stripe/webhook`
   - События: `checkout.session.completed`, `checkout.session.async_payment_succeeded`
   - Скопируйте *Signing secret* → `STRIPE_WEBHOOK_SECRET`.
4. Тест: используйте ключи `sk_test_...` и карту `4242 4242 4242 4242`.

## Юридические страницы (Испания)
`/aviso-legal` (LSSI ст. 10), `/privacidad` (RGPD), `/condiciones` (условия и отказ от покупки), `/cookies` — на ES (основная версия), EN и RU.
Данные владельца подставляются из переменных `LEGAL_*`; пока они не заданы, на страницах видна жёлтая пометка.
- При регистрации — обязательная галочка «принимаю Условия и Политику конфиденциальности» (дата и версия сохраняются).
- Перед оплатой — отдельная галочка о немедленном начале услуги (ст. 98.8, 108.3 TRLGDCU); фиксируется в метаданных Stripe и в таблице payments.
- Политика возврата: в течение 14 дней возвращается стоимость неиспользованных кредитов пакета (вручную: возврат в Stripe + списание кредитов в админке).
- Удаление аккаунта (RGPD ст. 17) — в меню аккаунта; оплаты сохраняются для бухгалтерии.
- Шрифт Manrope раздаётся с нашего сервера, cookies только технические → баннер cookies не нужен.
Тексты — шаблон, не юридическая консультация: покажите их своему gestor/абогадо.

## Свои демо-фото на главной
Положите `public/demo/before.jpg` и `public/demo/after.jpg` (3:2) — они заменят иллюстрацию в блоке «до/после».

## Важно
- Виртуальная меблировка и замена неба меняют фото. На порталах (Idealista, Fotocasa, MLS) такие фото нужно помечать — пометка включена по умолчанию.
- Результаты хранятся на CDN fal.ai; в истории хранятся превью исходников.
